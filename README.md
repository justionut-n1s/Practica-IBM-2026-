# Practica IBM Vara 2026 - Proiect React

## Tema

Frontend Internship Project - E-commerce Landing Page

Scopul proiectului este sa transform un design din Figma intr-o aplicatie 
React curata, folosind Atomic Design si metodologia BEM pentru stilizare.

Design (Figma): https://www.figma.com/design/JgM3iNzg4Pn6LSyUm3mQvK/97--Ecommerce-Landing-Page-With-Dashboard--Community-

Cerinte principale:
- React cu functional components
- Atomic Design (atoms / molecules / organisms / templates / pages)
- CSS cu BEM (fara inline styles, fara Tailwind)
- Layout responsive (desktop / tableta / mobil)
- Componente reutilizabile, fara cod duplicat
E doar scheletul de aplicatie, fara continut inca - App.jsx e gol (return null),
doar ca sa verificam ca merge Vite + structura de foldere e pregatita dinainte.

## Structura foldere

src/components/atoms  
src/components/molecules 
src/components/organisms 
src/pages - paginile efective
src/assets - poze si iconite
src/styles - variabile.css cu culorile/fonturile din design (Figma)

Folderele goale au inauntru un fisier .gitkeep, doar ca sa apara in git
(git nu tine minte foldere goale).
